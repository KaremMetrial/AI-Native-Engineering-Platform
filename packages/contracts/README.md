# Contracts

The OpenAPI specification and generated client types -- the single source of
truth for the API contract (D-110). Both `apps/web` and `apps/ai` consume
generated types from here rather than hand-writing them, so drift becomes a
build failure instead of a production defect.

## `openapi.json`

Generated by [dedoc/scramble](https://scramble.dedoc.co/) from `apps/api`'s
actual routes and `FormRequest` validation rules -- not hand-written, so it
cannot drift from the code the way a maintained-by-hand spec would.
Regenerate after any route, request, or response shape change:

```
cd apps/api
composer contract:export
```

CI fails the build if the committed file differs from a fresh export
(`.github/workflows/ci.yml`, the "Verify OpenAPI contract is up to date"
step) -- the same discipline applied to formatting and static analysis.

## `types/` (not yet generated)
